# ForeSeeMe - Project Context

## Project

ForeSeeMe is an AI-powered mobile healthcare application that predicts disease risk using environmental and health data.

---

## Current Phase

30% implementation completed.

Sprint 1 of the 60% implementation is beginning.

---

## Current Sprint Goal

Build the Risk module foundation.

This sprint DOES NOT include:

- Machine Learning
- Random Forest
- Weather APIs
- AQI APIs
- Dashboard UI
- Personalized Alerts

This sprint ONLY includes:

- Contracts
- Models
- Repository interfaces
- Use Cases
- Riverpod Providers
- Backend skeleton
- Firestore schema
- Docker setup
- Tests

---
